# 🏠 Sistema da corretora de imóveis PlusVida. 
Este projeto foi desenvolvido a partir de uma **regra de negócio criada por mim**, simulando um pequeno sistema de **cadastro e controle de imóveis**.  
A proposta foi aplicar os **conceitos de Programação Orientada a Objetos (POO)** em Java, **utilizando apenas os recursos solicitados pelo professor**, como **construtores, métodos e encapsulamento**.

## 📖 Contexto do Projeto
A **PlusVida**, uma corretora do mercado imobiliário, estava enfrentando dificuldades para manter sua competitividade, perdendo espaço para concorrentes que ofereciam melhores condições e serviços.  
Para resolver isso, foi desenvolvido um **sistema informatizado de controle de imóveis**, com o objetivo de **otimizar as operações de venda, aplicar descontos automáticos e classificar os imóveis conforme seu valor de mercado**.

## 🧪 Teste de Unidade

Ao longo desse projeto, quis ir um pouco além, buscando entender também como validar se aquilo que desenvolvi estava funcionando corretamente.
Dando continuidade ao projeto, decidi explorar a etapa de testes de software, colocando em prática os conhecimentos sobre validação de regras de negócio.
Para isso, realizei um teste de unidade, sem utilizar frameworks de automação como JUnit. Escolhi um método específico e defini diferentes cenários para verificar cada possibilidade de comportamento.

A ideia foi comparar os resultados obtidos com os resultados esperados e entender melhor como os testes contribuem para a qualidade do software.

## ⚙️ Funcionalidades
- Armazena informações sobre imóveis, como **identificação, tipo, preço e endereço**.  
- Permite **consultar e alterar dados** por meio de métodos específicos.   
- Permite **ranquear os imóveis** de acordo com seu valor, classificando-os como *TOP*, *Médio* ou *Abaixo*.  
- Aplica **descontos automáticos** conforme a faixa de preço, tornando o sistema mais dinâmico e próximo de uma aplicação real.
